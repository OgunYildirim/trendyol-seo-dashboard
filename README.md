## 🚀 Hızlı Başlangıç

### 1. Kurulum

```bash
# Dosyaları indirin
git clone https://github.com/yourusername/trendyol-dashboard-pro.git

# Klasöre gidin
cd trendyol-dashboard-pro

# index.html dosyasını tarayıcıda açın
```

### 2. İlk Kullanım

1. **Dashboard'u açın:** `index.html` dosyasına çift tıklayın
2. **Verileri inceleyin:** Demo veriler otomatik yüklenir
3. **Özellikleri keşfedin:** Butonlara tıklayın, grafikleri görün
4. **Rapor indirin:** "Detaylı Rapor" butonuna tıklayın

### 3. Kendi Verilerinizi Kullanın

`script.js` dosyasını açın ve değerleri güncelleyin:

```javascript
// Kendi metriklerinizi girin
function animateStats() {
    animateValue('totalRevenue', 0, 142580, 2000, '₺', true); // Gelir
    animateValue('totalOrders', 0, 1247, 2000, ''); // Sipariş
    // ...
}
```
